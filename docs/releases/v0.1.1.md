Token Glance v0.1.1 adds an app icon. Nothing else in the app changed: the app code, the Claude
limits hook and the settings are the same as in v0.1.0.
Setup, privacy details and troubleshooting are in the
[README](https://github.com/yim0327/token-glance#english).

## Requirements

- macOS 14 or later
- **Apple Silicon (arm64) only.** The zip contains an arm64 build; Intel Macs are not supported by
  this download (build from source on Intel instead; not tested).

## What's changed

- New app icon: two eyes looking over a usage bar. Until v0.1.0 the app had no icon, so macOS
  showed the generic app icon. The icon is Token Glance's own design and uses no Anthropic or
  OpenAI mark. It shows in Finder (icon and list views) and in Get Info. Token Glance is a menu bar
  app, so it never appears in the Dock. How the icon looks in the consent dialogs and notification
  banners has not been checked yet.
- Docs: the README has the icon and light-mode screenshots, and installation is described step by
  step in the [install guide](https://github.com/yim0327/token-glance/blob/main/docs/install.md#english).

## Install

1. Download `TokenGlance-0.1.1-macos-arm64.zip` and `TokenGlance-0.1.1-macos-arm64.zip.sha256`.
2. Check the download: `shasum -a 256 -c TokenGlance-0.1.1-macos-arm64.zip.sha256`
3. Unzip it in Finder and drag `TokenGlance.app` in Finder into **Applications** (`/Applications`).
   When the app was moved with `mv` in Terminal instead, it was observed running from an App
   Translocation path (a temporary location chosen by macOS). "Open at login" is tied to the app's
   location, so turn it on after moving the app.
4. The app is ad hoc signed and **not notarized**. The first time you open it, macOS blocks it.
   Open **System Settings › Privacy & Security** and choose **Open Anyway** for Token Glance, then
   open it again. Only do this for a download you have verified.

## Updating from v0.1.0

1. Quit Token Glance (details panel › **Quit**).
2. In Finder, replace `TokenGlance.app` in **Applications** with the new one (check its checksum
   first).
3. Open it again.

Settings are kept: they are stored under the app identifier (`io.github.yim0327.token-glance`), which
the build script sets to the same value for every release.
The Claude limits hook keeps working, because `settings.json` points to its installed copy in
`~/Library/Application Support/TokenGlance/bin`, not to the app. Replacing the app does not update
that copy. The hook code has not changed since v0.1.0.

## Known limitations

- Not notarized; Apple Silicon only.
- Claude limits update only while Claude Code runs (unless the optional online check is on).
- Claude online checks are not an official, supported API; they may change or stop without notice,
  and the hook cache is shown then.
- Codex sessions idle for more than 24 hours and then resumed may update only with the 5-minute
  fallback poll.
- Notifications are not sent retroactively for changes while the Mac slept or the app was closed.
  Threshold-crossing alerts are covered by automated tests; a real crossing has not been observed
  yet.
- With Codex online checks on, the App Server child adds about 40 MB (combined footprint above
  the 50 MB target).
