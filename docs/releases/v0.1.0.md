First release of Token Glance: Claude Code and Codex usage limits at a glance, in the macOS menu bar.

## Requirements

- macOS 14 or later
- **Apple Silicon (arm64) only.** The zip contains an arm64 build; Intel Macs are not supported by
  this download (build from source on Intel instead; not tested).

## What's included

- Two-line menu bar label with the remaining (or used) percentage of the 5-hour and weekly limits,
  orange at 30% left or less, red at 10%, and `--` with a reason when a value is missing.
- Details panel: per-window gauges (filled with what is left, or what is used, following the menu
  bar setting), reset time with a live countdown, tokens today and this week
  (input / output / cache, top models).
- Claude limits through a statusline hook that chains your existing statusline; install, repair
  and uninstall from Settings (backs up `settings.json` first, after your confirmation).
- Codex limits and tokens from local session logs, updated within seconds of new activity.
- Optional notifications (off by default) at 30% / 10% left (configurable) and when a new window
  starts after running low.
- English and Korean.
- 14-day history window with daily tokens per tool, from local logs.
- Optional online limit checks for Codex (App Server) and Claude (Claude Code's experimental
  `get_usage`), both off by default and enabled only after a consent dialog. When on, the installed
  tool runs as a child process and makes network requests with its own login. See the README's
  "Online checks and privacy" and "Limitations" sections.

## Install

1. Download `TokenGlance-0.1.0-macos-arm64.zip` and `TokenGlance-0.1.0-macos-arm64.zip.sha256`.
2. Check the download: `shasum -a 256 -c TokenGlance-0.1.0-macos-arm64.zip.sha256`
3. Unzip and move `TokenGlance.app` to `/Applications`.
4. The app is ad hoc signed and **not notarized**. The first time you open it, macOS blocks it.
   Open **System Settings › Privacy & Security** and choose **Open Anyway** for Token Glance, then
   open it again. Only do this for a download you have verified.

## Known limitations

- Not notarized; Apple Silicon only.
- Claude limits update only while Claude Code runs (unless the optional online check is on).
- Claude online checks are not an official, supported API; they may change or stop without notice,
  and the hook cache is shown then.
- Codex sessions idle for more than 24 hours and then resumed may update only with the 5-minute
  fallback poll.
- Notifications are not sent retroactively for changes while the Mac slept or the app was closed.
  Threshold-crossing alerts are covered by automated tests; a real crossing was not observed
  before this release.
- With Codex online checks on, the App Server child adds about 40 MB (combined footprint above
  the 50 MB target).
